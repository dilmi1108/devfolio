# Portfolio

A modern personal portfolio built with React and Vite. This site showcases professional experience, featured projects, technical skills, certifications, and contact details for Dilmi Sooriyaarachchi.

## Features

- Responsive single-page portfolio layout
- Animated loading screen and smooth scrolling experience
- Dark and light theme support
- Hero, About, Skills, Services, Projects, Experience, Achievements, Certifications, and Contact sections
- GitHub stats and social links
- SEO-friendly metadata for better discoverability

## Tech Stack

- React 19
- Vite
- Tailwind CSS
- Framer Motion
- React Icons
- EmailJS

## Getting Started

### Prerequisites

- Node.js installed on your machine
- npm installed with Node.js

### Install Dependencies

```bash
npm install
```

### Run the Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

### Preview the Production Build

```bash
npm run preview
```

### Lint the Project

```bash
npm run lint
```

## Project Structure

- `src/components` contains the reusable UI sections
- `src/context` contains shared state such as the theme provider
- `src/data` contains portfolio content and profile information
- `public` contains static assets and redirect configuration

## Deployment

The project is configured for deployment on Vercel. If you deploy somewhere else, make sure the routing and build output settings match the Vite production build.
